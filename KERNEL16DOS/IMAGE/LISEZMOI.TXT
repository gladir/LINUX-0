LINUX-0 KERNEL16DOS - images disque
=================================

LINUX144A.IMG  Disquette 1,44 Mo amorcable : noyau (IO.SYS), shell et
               commandes de base (\BIN), \ETC\PROFILE,
               \ETC\SYSCTL.D\CUSTOM.CFG (configuration du noyau).
LINUX144B.IMG  Disquette 1,44 Mo : suite des commandes (B:\BIN).
LINUX.ISO      CD-ROM amorcable (El Torito, emulation de disquette 2,88 Mo qui
               contient tous les fichiers : c'est le lecteur A:). Lecture seule
               sur un vrai CD : pas de tuyaux dans le shell.

Demarrage sous QEMU :
  qemu-system-i386 -fda LINUX144A.IMG -fdb LINUX144B.IMG -boot a
  qemu-system-i386 -cdrom LINUX.ISO -boot d

Disque dur (non fourni, 32 Mo) : HD=32 ../BUILD.SH images
  puis qemu-system-i386 -hda LINUXHD.IMG

Langue : ajouter dans \ETC\SYSCTL.D\CUSTOM.CFG la ligne
  env.LANGUAGE = EN   (anglais ; GR allemand, SP espagnol, IT italien)
Francais par defaut. Dans le shell : export LANGUAGE=EN

Reconstruire : ../BUILD.SH (Linux) ou ..\MAKEIMG.BAT (DOS/Windows).
Verifier une image : LSIMG LINUX144A.IMG /C
