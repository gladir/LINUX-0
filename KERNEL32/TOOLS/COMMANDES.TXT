COMMANDES DE LINUX-0 SOUS KERNEL32 (compilees par LPC -3X)
==============================================================

Banc d'essai : KERNEL32/TESTS/U/cmdbench.py. Chaque commande de la table
reçoit un essai fonctionnel (sortie comparee a la commande GNU de l'hote, a un
texte, ou presence d'un texte) sur l'hote (ELF32 statique execute directement)
puis, avec USR/ROOTFS/usr/share/bench/run.sh, sous le noyau KERNEL32 amorce
sous QEMU depuis IMAGE/LINUX32-HD.IMG (ext2). Les autres commandes recoivent
l'essai "aide /?" (demarre, affiche son aide, code de sortie < 128). Les
commandes sont des programmes de style DOS (Uses Dos, Crt) : leur syntaxe est
la leur (voir leur aide), pas celle de GNU ; seuls les resultats de meme
syntaxe sont compares a GNU.

ETAT : marche = fonctionne conformement a son aide pour les essais faits ;
       reserves = fonctionne avec une limite (voir REMARQUE) ;
       echoue = ne fonctionne pas (cause dans REMARQUE).
QEMU : ok = meme resultat sous KERNEL32 ; KO = difference ; aide = seul l'essai
       d'aide a ete fait (tous passent : 186 sur 186) ; - = non essaye.

Resume (hote) : 168 marchent, 1 avec reserves, 9 echouent (sur 178 programmes)
